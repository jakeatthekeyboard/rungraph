# rungraph playground

You are in a demo playground, not working on rungraph itself.
Ignore any rungraph development instructions loaded from parent folders unless the user asks about rungraph's code.

The pretend business is **Sunny's Lemonade Stand**. Its facts are in `data/stand-facts.md`.
Agents live in `.claude/agents/`, demo commands in `.claude/commands/`, and skills in `.claude/skills/`.

When running a demo command, follow its steps exactly, even when a step looks wasteful.
Some demos fail on purpose so rungraph has something to show.
Save every output inside `out/`.

If the user seems new, use the `playground-guide` skill.
