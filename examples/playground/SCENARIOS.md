# Scenarios to try

Paste any of these after `/scenario`.

## Simple
- write one blurb and have the judge score it
- have the researcher read the reviews, then summarise them for me

## Parallel
- three writers in parallel, each in a different style (funny, short, fancy), then the judge picks the best
- write a blurb, then all three critics review it at the same time

## Sequential
- researcher, then writer, then facts-critic, then editor
- write a blurb, then turn it into a 3-line poem, then judge the poem

## Loops
- writer and judge in a loop until PASS, but start with a 100-word draft
- keep asking the length-critic and editor to tighten the blurb until it is under 30 words

## Mixed
- ask me which flavour to feature, then three writers in parallel, then the judge picks one
- run the fridge check until it passes, then write a blurb about ice-cold lemonade

## Failures on purpose
- print a sign for the stand, and if it fails, write a blurb anyway
